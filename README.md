### 🎓 Undergraduate Thesis

**RMP-BYOL: Enhancing Rare Medicinal Plant Classification Using a Non-Contrastive Self-Supervised Learning Framework**

Developed a data-efficient medicinal plant classification framework combining Bootstrap Your Own Latent (BYOL), Vision Transformers (ViT), and Explainable AI (XAI).

- Achieved **98.92% classification accuracy** across 35 medicinal plant classes.
- Explored self-supervised representation learning for rare and common medicinal plant classification.
- Applied EigenCAM and Grad-CAM for model interpretability.
